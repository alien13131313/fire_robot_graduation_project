# 展場滅火機器人 AACO 自適應路徑規劃與決策樹模擬系統

本專案全面滿足以下 5 大核心修改需求：
1. **繪圖直觀標記**：起點為綠色（隨機人員點位計算）、出口為藍色（四方出口）、障礙物為黑色。
2. **歷史圖檔紀錄**：存檔區域支援點選載入上次與歷史圖檔紀錄（繼承已劃記之障礙物與出口）。
3. **資料夾模組化儲存**：自動儲存網格特徵至 `grid_features/`、決策樹更新至 `dt_updates/`、AACO 路徑更新至 `aaco_paths/`。
4. **無路徑自適應機制**：當傳統搜尋無法抵達目標時，自動更新禁行移動表、調升成本懲罰因子並重新嘗試，避免陷入無限重試或直接失敗。
5. **動態參數輸入**：提供網頁介面供使用者自行設定螞蟻數量與迭代上限。

## 執行方式
1. 安裝依賴套件：
```bash
pip install -r requirements.txt
```
2. 啟動網頁伺服器：
```bash
python app.py
```
3. 開啟瀏覽器訪問 http://127.0.0.1:5000 即可使用。
